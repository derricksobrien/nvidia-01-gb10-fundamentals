# NVIDIA GB10 Superchip Fundamentals

> **Track:** NVIDIA HPC & Developer Upskilling (Track 2)
> **Course 1 of 8**

Understand the Blackwell architecture, NVLink topology, and developer environment for the GB10 superchip.

---

## Modules

### Module 1: GB10 Architecture & Blackwell Cores

**Learning Objectives:**
- Identify GB10 core types and their roles
- Understand Blackwell generation improvements
- Compare GB10 to previous-gen chips

### Module 2: Memory Hierarchy & NVLink

**Learning Objectives:**
- Map HBM3 and LPDDR5 tiers
- Configure NVLink for multi-chip workloads
- Benchmark memory bandwidth

### Module 3: Developer Environment Setup

**Learning Objectives:**
- Install CUDA toolkit for GB10
- Configure Nsight development tools
- Validate environment with device queries

### Module 4: Benchmarking Your First Workload

**Learning Objectives:**
- Run standard ML benchmarks
- Interpret FLOPs and memory reports
- Establish performance baselines
